# Professional CV & Portfolio (2026)

This repository contains the source code for my professional portfolio and interactive curriculum vitae for 2026,  
deployed at [gabor.northweb.co.uk](https://gabor.northweb.co.uk/).

Designed with a focus on modern web standards, performance, and responsive layout, the platform showcases my professional background, technical expertise, work history, and project portfolio.

> Live Access: \
> [Production](https://gabor.northweb.co.uk/) / [Development](https://gabor.northweb.dev/)

## Features

- **Interactive CV Presentation:** Clean, structured, and modern layout tailored for recruiters and engineering teams.
- **Custom Design Architecture:** Built entirely from scratch without relying on external CSS frameworks or UI libraries.
- **Dynamic Content Loading:** Built with modular JavaScript to ensure smooth rendering and rapid load times.
- **Responsive Layout:** Fully customized grid and layout rules optimized for mobile, tablet, and desktop viewports.
- **Professional History & Skills Breakdown:** Detailed overview of technical proficiency, development workflows, and engineering milestones.

## Built With

- **HTML5:** Semantic markup structured for accessibility and modern SEO.
- **Custom CSS Architecture:** A completely bespoke, lightweight styling framework crafted from scratch.
- **JavaScript (ES6+):** Vanilla JavaScript for dynamic DOM manipulation and lightweight application logic.
